Penjelasan:<br>
`import json` berfungsi untuk memanggil fitur bawaan python agar program yang kita buat bisa membaca dan memakai data berformat json<br>
`with open` dan `json load` berfungsi untuk membaca data file json yang telah kita buat<br>
`while True` berfungsi untuk membuat perulangan terus-menerus tanpa henti. Jadi program terus menampilkan menu 1-3<br>
`(len(data) + 1)` berfungsi untuk menghitung jumlah data saat ini, dan kemudian menambah angka 1<br>
`json.dump` befungsi untuk menyimpan data yang baru ditambah dan di simpan secara permanen<br>
`break` berfungsi untuk menghentikan perulangan `while True` secara paksa<br>
